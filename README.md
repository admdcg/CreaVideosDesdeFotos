# CreaVideosDesdeFotos 🎬✨

¡Crea videos espectaculares gratis a partir de tus fotos con transiciones y música de fondo directamente en tu navegador, de forma instantánea y con **privacidad total**!

## 🚀 Características Principales

- **100% en el Navegador (Client-Side)**: Tus fotos se procesan de manera local y segura. Nunca se suben a ningún servidor de internet.
- **Importación Inteligente**: Arrastra y suelta tus fotos directamente en la cuadrícula de trabajo o selecciónalas desde tu disco.
- **Organización Interactiva**: Reordena las fotos arrastrándolas para cambiar la secuencia del video o úsalas con los accesos rápidos de orden alfabético e inversión.
- **Ajustes de Aspecto Cinemáticos**:
  - **Fondo Borroso (Efecto Cine)**: Rellena los bordes vacíos de fotos verticales o panorámicas con una versión difuminada de la misma foto.
  - **Barras Negras**: Mantiene el aspecto original sobre un fondo negro sólido.
  - **Recortar**: Llena por completo el encuadre (16:9).
- **Música Sincronizada**: Sube tu propia canción de fondo (MP3, WAV) o utiliza nuestra pista instrumental por defecto.
- **Renderizado Dinámico**: Barra de progreso con porcentaje en tiempo real y previsualizador de descarga del video final.

## 🛠️ Cómo Utilizar el Proyecto Localmente

No necesitas instalar servidores ni dependencias. ¡Simplemente abre el archivo principal en tu navegador!

1. Descarga o clona este repositorio:
   ```bash
   git clone https://github.com/admdcg/CreaVideosDesdeFotos.git
   ```
2. Entra en la carpeta del proyecto y haz doble clic sobre el archivo **`index.html`** para abrirlo en Chrome, Edge, Safari o Firefox.
3. ¡Comienza a crear tus videos!
